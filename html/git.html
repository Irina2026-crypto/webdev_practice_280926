Git

  • git init — создаёт локальный Git репозиторий в текущей папке .
  • git clone — скачивает удалённый репозиторий (например, с GitHub) и создаёт локальную копию.
  • git status — показывает текущее состояние: какие файлы изменены, какие добавлены в индекс, какие не отслеживаются.
  • git push — отправляет локальные коммиты на удалённый сервер.
  • git pull — загружает изменения с удалённого репозитория и сразу объединяет их с локальной версией (комбинация fetch + merge).
